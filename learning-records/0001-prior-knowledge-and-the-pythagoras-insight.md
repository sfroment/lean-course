# Prior knowledge and the "Pythagoras" insight

Sacha disclosed: high-school math background, and strong programming experience across C, OCaml, Go, Rust, C++, Python, TypeScript, bash — including functional programming. He explicitly asked to start the *math* from nothing: "it's not because I know Pythagoras that I don't need to prove it, right?" — which is exactly right. In Lean/mathlib every theorem is proved from axioms; knowing a result is a map of the territory, not the proof.

## Evidence

Stated in the mission interview (session 1): chose "high-school math" but with the explicit note to treat it as from-nothing; interests span number theory, algebra, geometry/topology, and the logical foundations — he wants the full picture.

## Implications

- Teach logic and type theory from zero; do not skip foundations because of prior math exposure.
- Programming-side concepts (functions, recursion, data structures) can move fast given his FP background.
- Never lean on mathlib lemmas as black boxes early — prove everything ourselves first, then learn to *reuse* mathlib properly.
- Long-horizon plan: foundations → numbers/number theory → algebra → analysis → topology → category theory, each with original proofs by him.
