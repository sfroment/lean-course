Lesson 0007 · Phase A — Foundations

Rewriting with rw and the equality API

Builds on Lesson 0006. 20–30 minutes.

The one idea

An equality h : a = b is a license to replace a by b anywhere. rw [h] does that replacement in the goal; h.trans, h.symm, congrArg manipulate equalities as values.

1. The equality API

example (a b c : Nat) (h : a = b) (h2 : b = c) : a = c := h.trans h2
example (a b : Nat) (h : a = b) : b = a := h.symm

Every equality has methods: h.trans h2 chains (a = b and b = c give a = c), h.symm flips it. These are just theorems about Eq applied to h.

2. The rw tactic

example (a b c : Nat) (h : a = b) (h2 : b = c) : a = c := by
  rw [h, h2]

rw [h] rewrites occurrences of the left side of h into the right side, in the goal. rw [h, h2] does both in sequence: goal a = c → b = c → c = c, which closes by reflexivity automatically.

3. Rewriting under a function (congruence)

example (f : Nat → Nat) (a b : Nat) (h : a = b) : f a = f b := congrArg f h

example (f : Nat → Nat) (a b : Nat) (h : a = b) : f a = f b := by
  rw [h]

If a = b then f a = f b for any function f. congrArg f h builds this in term style; rw [h] does it in the goal.

4. Try it yourself

-- playground/MyScratch.lean
example (a b : Nat) (h : a = b) : a + 0 = b + 0 := by
  rw [h]

example (a b c d : Nat) (h : a = b) (h2 : c = d) : a + c = b + d := by
  rw [h, h2]
