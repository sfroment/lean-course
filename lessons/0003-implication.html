Lesson 0003 · Phase A — Foundations

Implication: proving P → Q

Builds on Lesson 0002. 20–30 minutes.

The one idea

A proof of P → Q is a function that turns any proof of P into a proof of Q. So "assume P, derive Q" is literally "write a function".

1. Term style: just a function

example (P Q : Prop) (h : P → Q) (hP : P) : Q := h hP

example (P Q : Prop) : (P → Q) → P → Q := fun h hP => h hP

Given h : P → Q and hP : P, the proof of Q is simply h hP — function application. And proving (P → Q) → P → Q is the identity function on proofs, written fun h hP => h hP.

2. Tactic style: intro and exact

example (P Q : Prop) (h : P → Q) : P → Q := by
  intro hP
  exact h hP

In tactic mode (by), intro hP says "assume P" — it moves the hypothesis into the context and the goal becomes Q. exact t closes the goal with the term t if its type matches exactly.

3. Chaining implications

example (P Q R : Prop) (hPQ : P → Q) (hQR : Q → R) : P → R := by
  intro hP
  exact hQR (hPQ hP)

To prove P → R from P → Q and Q → R: assume hP : P, get hPQ hP : Q, then hQR (hPQ hP) : R. This is pure function composition — transitivity of implication, proven by you.

4. Try it yourself

-- In playground/MyScratch.lean:
example (P Q R S : Prop) (hPQ : P → Q) (hQR : Q → R) (hRS : R → S) : P → S := by
  intro hP
  exact hRS (hQR (hPQ hP))

Exercises ✏️

Do these in the ✏️ Write pad or in playground/MyScratch.lean. Press ▶ Run there to execute on the site.

E1 — flip the arrow · ✏️ write it

example (P Q : Prop) (h : Q → P) (hQ : Q) : P := by
  sorry
Solution
example (P Q : Prop) (h : Q → P) (hQ : Q) : P := by
  exact h hQ

E2 — two hypotheses at once · ✏️

example (P Q R : Prop) : (P → Q → R) → (P → Q) → P → R := by
  sorry
Solution
example (P Q R : Prop) : (P → Q → R) → (P → Q) → P → R := by
  intro h hpq hp
  exact h hp (hpq hp)

E3 — compose two implications · ✏️

example (P Q R : Prop) (hPQ : P → Q) (hQR : Q → R) : P → R := by
  sorry
Solution
example (P Q R : Prop) (hPQ : P → Q) (hQR : Q → R) : P → R := by
  intro hp
  exact hQR (hPQ hp)
