Lesson 0005 · Phase A — Foundations

Negation ¬, False, and classical logic

Builds on Lesson 0004. 20–30 minutes.

The one idea

¬P is defined as P → False: "not P" means "P leads to a contradiction". And from False anything follows. Up to here everything was constructive; now we add the classical axioms.

1. ¬ is just → False

#check Not   -- Not (a : Prop) : Prop

example (P : Prop) (h : ¬P) (hP : P) : False := h hP

¬P unfolds to P → False. So a proof of ¬P applied to a proof of P yields False — the contradiction.

2. Ex falso: from False, anything

example (P : Prop) (h : False) : P := False.elim h

False has no proofs (that's the point), but if you ever had one, False.elim derives any proposition from it. In logic this is called ex falso quodlibet.

3. A useful pattern: contraposition

example (P Q : Prop) : (P → ¬Q) → Q → ¬P := fun h hQ hP => h hP hQ

Read it: if P implies not-Q, then Q implies not-P. Unfold the ¬'s and it's just function composition again.

4. Classical logic: the law of excluded middle

#check Classical.em   -- Classical.em (p : Prop) : p ∨ ¬p

example (P : Prop) : P ∨ ¬P := Classical.em P

#check Classical.byContradiction   -- (¬p → False) → p

example (P : Prop) (h : ¬¬P) : P := Classical.byContradiction (fun hnp => h hnp)

Everything so far was constructive — every proof built an actual witness. Classical logic adds Classical.em: every proposition is either true or false, no third option. With it, double negation elimination (¬¬P → P) follows via Classical.byContradiction. Lean accepts these because they're declared as axioms (ultimately resting on Classical.choice) — the kernel tracks this: you can always ask #print axioms which axioms a theorem used. Nothing is hidden.

5. Try it yourself

-- In playground/MyScratch.lean.
-- Classically, double-negation elimination always works:
example : ¬¬(2 = 2) → 2 = 2 := fun h => Classical.byContradiction (fun hnp => h hnp)

-- Teaser (leave as sorry for now): prove the same WITHOUT Classical,
-- using that 2 = 2 is decidable. Hint from Lesson 0006: decide.
example : ¬¬(2 = 2) → 2 = 2 := by
  sorry

(That last one is a teaser — in general ¬¬P → P needs classical logic, but for decidable P you can do it constructively. We'll see how in Lesson 0006.)

Exercises ✏️

Do these in the ✏️ Write pad or in playground/MyScratch.lean. Press ▶ Run there to execute on the site.

E1 — prove ¬¬P from P · ✏️ write it

example (P : Prop) (h : P) : ¬¬P := by
  sorry
Solution
example (P : Prop) (h : P) : ¬¬P := by
  intro hnp
  exact hnp h

E2 — contraposition · ✏️

example (P Q : Prop) (h : P → Q) (hnq : ¬Q) : ¬P := by
  sorry
Solution
example (P Q : Prop) (h : P → Q) (hnq : ¬Q) : ¬P := by
  intro hp
  exact hnq (h hp)

E3 — double negation, classically · ✏️

example : ¬¬(2 = 2) → 2 = 2 := by
  sorry
Solution
example : ¬¬(2 = 2) → 2 = 2 := by
  intro h
  exact Classical.byContradiction (fun hnp => h hnp)
