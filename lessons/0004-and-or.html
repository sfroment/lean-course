Lesson 0004 · Phase A — Foundations

Conjunction ∧ and disjunction ∨

Builds on Lesson 0003. 20–30 minutes.

The one idea

P ∧ Q is proved by giving both proofs; a proof of P ∧ Q gives you both. P ∨ Q is proved by giving one side — and used by case analysis.

1. Conjunction: And

example (P Q : Prop) (hP : P) (hQ : Q) : P ∧ Q := And.intro hP hQ

example (P Q : Prop) (h : P ∧ Q) : P := h.left
example (P Q : Prop) (h : P ∧ Q) : Q := h.right

And.intro hP hQ builds P ∧ Q from proofs of both parts. From a proof h : P ∧ Q, the projections h.left and h.right extract the two proofs. (h.1 and h.2 also work.)

2. Disjunction: Or

example (P Q : Prop) (hP : P) : P ∨ Q := Or.inl hP
example (P Q : Prop) (hQ : Q) : P ∨ Q := Or.inr hQ

To prove P ∨ Q you only need one side: Or.inl (left) or Or.inr (right).

3. Using a disjunction: case analysis

-- term style:
example (P Q R : Prop) (h : P ∨ Q) (hP : P → R) (hQ : Q → R) : R :=
  Or.elim h hP hQ

-- tactic style:
example (P Q R : Prop) (h : P ∨ Q) (hP : P → R) (hQ : Q → R) : R := by
  cases h with
  | inl h1 => exact hP h1
  | inr h2 => exact hQ h2

From h : P ∨ Q you can't extract a specific side — but if both cases lead to R, then R holds. Or.elim does this in term style; cases h with | inl … | inr … does it in tactic style, splitting into two goals.

4. Try it yourself

-- ∧ is commutative:
example (P Q : Prop) (h : P ∧ Q) : Q ∧ P := And.intro h.right h.left

-- a classic: from P ∧ (P → Q) conclude Q (modus ponens)
example (P Q : Prop) (h : P ∧ (P → Q)) : Q := h.right h.left
