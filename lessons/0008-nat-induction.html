Lesson 0008 · Phase A — Foundations

Natural numbers and induction

Builds on Lesson 0007. 30–40 minutes — this is the first real proof technique.

The one idea

To prove something for every natural number, prove it for 0, and prove that if it holds for n then it holds for n+1. That's induction — and it's built into the definition of Nat itself.

1. Nat and its core lemmas

#check Nat.succ_add   -- n.succ + m = (n + m).succ
#check Nat.add_zero   -- n + 0 = n
#check Nat.add_succ   -- n + m.succ = (n + m).succ
#check Nat.zero_add   -- 0 + n = n

Nat is built from 0 and succ (i.e. n+1). Lean core already proves the basic facts above — we can use them with rw while we learn to prove our own.

2. Your first induction

example (n : Nat) : n + 0 = n := by
  induction n with
  | zero => rfl
  | succ n ih => rw [Nat.succ_add, ih]

How to read it:

  • induction n with splits into two goals: the zero case and the succ n ih case, where ih is the induction hypothesis — the statement already proved for n.
  • zero: goal 0 + 0 = 0, closed by rfl.
  • succ: goal (n+1) + 0 = n+1. rw [Nat.succ_add] turns it into (n + 0) + 1 = n + 1… in arrow form succ (n + 0) = succ n; then rw [ih] replaces n + 0 by n, giving succ n = succ n, closed automatically.

(Of course core already has this as Nat.add_zero: example (n : Nat) : n + 0 = n := Nat.add_zero n. We re-prove it to learn the technique — remember the mission: everything gets re-proven.)

3. Stretch: commutativity of addition

example (a b : Nat) : a + b = b + a := by
  induction a with
  | zero => rw [Nat.zero_add, Nat.add_zero]
  | succ a ih => rw [Nat.succ_add, ih, Nat.add_succ]

Induction on a, using b fixed. Zero case: 0 + b = b + 0 — rewrite both sides to b. Step case: (a+1) + b = b + (a+1) — peel the succ off the left, use ih, peel the succ off the right with Nat.add_succ.

4. Try it yourself

-- playground/MyScratch.lean
example (n : Nat) : 0 + n = n := by
  induction n with
  | zero => rfl
  | succ n ih => rw [Nat.zero_add, ih]

(This one is easy because core's Nat.zero_add does the heavy lifting in the step. For a real workout, try example (n : Nat) : n * 1 = n or 2 * n = n + n — ask me for hints!)
