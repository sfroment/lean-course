Lesson 0009 · Phase A — Foundations

Tactic toolkit: have, calc, apply, show, assumption

Builds on Lesson 0008. 20–30 minutes. This lesson is a toolbox, not a new concept.

1. have — prove a stepping stone

example (P Q R : Prop) (hPQ : P → Q) (hQR : Q → R) (hP : P) : R := by
  have hQ : Q := hPQ hP
  exact hQR hQ

have hQ : Q := proof adds a new hypothesis with a proof, exactly like in a paper proof ("we first show Q…").

2. calc — chain equalities readably

example (a b c : Nat) (h : a = b) (h2 : b = c) : a = c := by
  calc a = b := h
    _ = c := h2

calc writes a chain of (in)equalities, each justified by a proof on the right. _ means "the right-hand side of the previous step".

3. apply — work backwards

example (P Q : Prop) (h : P → Q) (hP : P) : Q := by
  apply h
  exact hP

apply h on goal Q with h : P → Q replaces the goal by P — backwards reasoning: "to prove Q, it suffices to prove P".

4. assumption and show

example (P Q : Prop) (h : P → Q) (hP : P) : Q := by
  apply h
  assumption

example (P : Prop) (h : P) : P := by
  show P
  assumption

assumption closes the goal if some hypothesis has exactly that type. show P restates the goal (a readability/documentation move; fails if it doesn't match).

5. Putting it together

example (P Q R : Prop) (hPQ : P → Q) (hQR : Q → R) (hP : P) : R := by
  apply hQR
  apply hPQ
  assumption

Goal R ← apply hQR → goal Q ← apply hPQ → goal P ← assumption finds hP. Backwards proof, three lines.

E2 — calc a chain · ✏️

example (a b c d : Nat) (h1 : a = b) (h2 : b = c) (h3 : c = d) : a = d := by
  sorry
Solution
example (a b c d : Nat) (h1 : a = b) (h2 : b = c) (h3 : c = d) : a = d := by
  calc a = b := h1
    _ = c := h2
    _ = d := h3

E3 — apply backwards · ✏️

  sorry
Solution
example (P Q R S : Prop) (hPQ : P → Q) (hQR : Q → R) (hRS : R → S) (hP : P) : S := by
  apply hRS
  apply hQR
  apply hPQ
  assumption
