Lesson 0006 · Phase A — Foundations

Decidable propositions and decide

Builds on Lesson 0005. 20–30 minutes.

The one idea

Some propositions can be settled by computation. For those, by decide is a complete proof — Lean evaluates the proposition to true and the kernel accepts it.

1. decide on numbers and booleans

example : 2 + 2 = 4 := by decide
example : (3 : Nat) < 5 := by decide
example : ¬ (2 = 3) := by decide
example : true && false = false := by decide

Equality, <, and boolean operations on Nat have Decidable instances: Lean knows how to compute a yes/no answer. decide runs that computation and, if the answer is yes, closes the goal.

2. Three ways to prove an equality

ToolWhen it worksExample
rflBoth sides are definitionally equal (compute to the same thing)example : 2 + 2 = 4 := rfl
by decideThe proposition is decidable and computes to trueexample : 2 * 3 = 6 := by decide
by simpA simplification lemma closes it (core has a few)example (n : Nat) : n + 0 = n := by simp

rfl is about definitional equality; decide is about decidable computation. They overlap a lot on concrete numbers but are different mechanisms. (sorry is the fourth "way" — it never counts as a proof, it just silences the error with a warning.)

3. Booleans and if

#eval if true then 1 else 0   -- 1

example (b : Bool) : (if b then 1 else 0) = 1 ∨ (if b then 1 else 0) = 0 := by
  cases b with
  | true => exact Or.inl rfl
  | false => exact Or.inr rfl

Bool is true | false, and if b then x else y branches on it. Note the difference: if lives in Bool/data, while →, ∧ live in Prop. Propositions are not booleans — that's why decide exists: it bridges them safely for decidable propositions.
